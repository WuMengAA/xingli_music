- **建议**：以 `API_CONTRACT_FROZEN.md` §3 为唯一真源优先（说法 A）；若批次 B 已落地说法 B，则需在 API 契约内回填修订并同步 `PROJECT_STATE`/`TODO`，否则属契约被破坏。

- `ARCHITECTURE_V2_增量.md` 已改用 `shellPageIndexProvider`（见 v2 §3.2.5 / M6 绑定）。
- **状态**：v2 已对齐；**v1 架构文档 §1.5 未回填**，仍误导。建议修订 v1 架构文档注释。

### C-3 设置分类枚举命名冲突（SettingsCategory vs SettingsSection）
- `ARCHITECTURE_UI_重构.md` §1.5 称 `SettingsCategory { playback, source, scene, notification, about }`。
- `API_CONTRACT_FROZEN.md` §4 终裁：`SettingsSection`(enum，值相同)。
- `ARCHITECTURE_V2_增量.md` / `class-diagram.mermaid` 已统一为 `SettingsSection` 且 **v2 新增第 6 槽 `experiment`**。
- **状态**：v2 已对齐；v1 架构文档 §1.5 名称过时。建议回填。

### C-4 iOS 最低版本冲突

### C-5 协作模型表述冲突（单人写入 vs 多专家并行）

## F. 2.5D / 体素 / 空间音效编辑器相关一切

> 汇总 2.5D 编辑器、3D 体素世界演进、空间音效引擎的所有描述。引用标注来源。

### F-1 2.5D 音效编辑器（v2 正式交付形态）
来源：`ARCHITECTURE_V2_增量.md` M5/M5附 + `class-diagram.mermaid` + `_draft_code_facts.md` 四 + `QA_REPORT_V2.md` M5。

- **定位**：M5-1，等距/俯视方块画布 + 音效块面板 + 底部工具栏（试听/播放/撤销/重做/保存/清空）；竖屏画布居中面板在上，横屏画布居左面板居右（`ARCHITECTURE_V2_增量.md` M5）。
- **共享 2.5D 基础**：小游戏（M2-D）与编辑器（M5-1）共享 `VoxelCanvasController` + `VoxelCanvasView`（纯 CustomPaint，零第三方 3D 依赖，`ARCHITECTURE_V2_增量.md` §0 Q3 / M5附）。
- **核心类**：
  - `VoxelBlockType`：音效块预设（id/名称/图标/sfxKey/baseVolume/颜色）。
  - `VoxelSoundScene`：保存模型（id/name/`Map<"x,y", blockTypeId>`），toJson/fromJson。
  - `VoxelCanvasController`(ChangeNotifier)：网格尺寸、方块表、选中类型、add/remove/undo/redo/clear、load/toScene；undo/redo 栈上限 64。
  - `VoxelCanvasView`(CustomPaint)：等距菱形瓦片 + 顶面/左右侧面 + 选中高亮 + 手势命中（像素→网格坐标）。
  - `SoundBlockMixer`：按方块数量→音量、x 位置→左右声道权重，经 `AudioService.playSfx` 一次性/循环播放，preview/stop。
- **坐标约定**：网格 `(col,row)`，key=`"$col,$row"`；等距投影 `screenX=(col-row)*tileW/2+offsetX`，`screenY=(col+row)*tileH/2+offsetY`（`ARCHITECTURE_V2_增量.md` §3.2.3；QA 单测投影正逆变换一致）。
- **保存流**：选块→setBlock 入 undo 栈→试听（SoundBlockMixer 按数量混音循环）→保存 `toScene` → `voxelSoundScenesProvider.save` → SharedPreferences `voxel_sound_scenes_v1`（`ARCHITECTURE_V2_增量.md` §4.3）。
- **验收**：P0-M5-1 代码链完整；P1-M5-5 撤销/重做单测全过；P1-M5-6 场景包导出通过（`QA_REPORT_V2.md` M5）。
