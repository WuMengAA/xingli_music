# 星璃音乐 · 前端 UI 选型（2026-09-03）

## 依据：design-md 设计库
来源：`D:\Stellara\.md\design-md\`（70+ 品牌设计规范分析，每目录含 DESIGN.md）。

本版对比阅读：**Spotify / Apple / Linear / Notion / Raycast**，为星璃音乐（音乐播放器）
选出最合适的前端 UI 方向。

## 结论：Spotify 式「内容优先深色沉浸」

对音乐 App，**Spotify** 的设计哲学最契合：
- **UI 退后、内容发光**：近黑炭层（#121212→#1f1f1f）作为基底，专辑封面/正在播放内容成为
  唯一的色彩来源（"content-first darkness"）。
- **单一品牌 accent**：Spotify 用绿 #1ed760，星璃用品牌紫（皮肤主色，`themeSkinColorProvider`
  驱动，深色下 `withSkin` 自动提亮 +0.12 lightness 保证可读）。
- **pill/circle 几何**：主按钮全圆角胶囊、播放按钮正圆、输入框胶囊。
- **字重层级**：700（导航/强调）/ 600（次级）/ 400（正文）。

对比落选：
- **Apple**（摄影优先、浅画布、负字距大标题）——更适合产品营销页，非播放器沉浸场景。
- **Linear**（近黑 #010102 + 薰衣草蓝、技术文档感）——工程工具风，缺音乐氛围。
- **Notion**（浅色 pastel 卡片、多色彩）——工作区风，与"让封面说话"冲突。
- **Raycast**（命令面板风、白色 CTA）——开发者工具感。

## 落地（R33，commit 见 MEMORY）
1. **深色表面层级** → Spotify 炭黑三级（`AppDarkColors`）：
   - `bg` #000000 → **#121212**（一级页底，避免死黑）
   - `surface` #1C1C1E → **#1A1A1A**（二级容器）
   - `surfaceHigh`/`placeholder` #2C2C2E → **#242424**（三级/选中态）
2. **accent 已跟皮肤**（`withSkin` 深色提亮），保留。
3. 原生极简基底（`kNativeMinimal=true`）不动——深色沉浸只在用户切深色/跟随系统时呈现。
