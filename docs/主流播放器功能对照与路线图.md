## 二、差距分析：优先级路线图

### P0（本轮/近期，性能体验基础）

1. **性能体系**：两档（性能/质量）+ fps 24/30/60/120 + 渲染后端选配 + 特效开关组 ← 用户本轮点名
2. **界面布局自定义**（密度/面板开关，最小可用版）
3. **media_kit 解码层**（用户已拍板 C 方案）：一次性解决格式全集/Hi-Res/无缝/交叉淡入/硬件加速 ← 大工程，单独轮次

### P1（补齐主流体验）

1. 频谱可视化（画布叠加）
2. 睡眠定时器
3. 播放列表导入导出（M3U8）
4. 智能播放列表/动态队列
5. 曲目信息面板（采样率/位深/码率）
6. ReplayGain 响度归一

### P2（锦上添花）

1. 标签编辑器、封面下载
2. 手势操作、第三方皮肤接口
3. 设置导出导入、Last.fm
4. .cue 分轨、高级随机

## 四、本轮交付范围（R21）

1. 性能档位三档 → **两档（性能/质量）**，旧值自动迁移
