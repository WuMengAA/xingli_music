## 四、核心模块设计要点

### 4.1 MusicSource 抽象（在线源统一接入）

```dart
abstract class MusicSource {
  String get sourceId;
  bool get enabled;
  Future<List<Track>> getTracks(...);
  Future<String?> resolveStreamUrl(Track track);   // 占位 uri → 真实播放地址
  Map<String, String> get playbackHeaders;          // 认证头（如 WebDAV Basic）
  bool get requiresMediaKit;                        // 后端路由标志
}
```

### 4.2 PlaybackStreamResolver（VFS 统一）

- **lib/ 播放占位**：`netease://`（网易云）、`webdav://<base64url(路径)>`（WebDAV）
- buildStreamResolver 统一解析：真实 URL + 认证头注入 + requiresMediaKit 路由到三后端

### 4.3 投屏（T11，已测）

- 端口 8741，被占 +1 重试；本地 Range 切片 206 / 远程代理透传
- 3 冒烟测试验证：Range 精确切片、HTML 页 200、无 uri 400

### 4.4 WebDAV（T12，已测）

- 纯 Dart：PROPFIND + Depth:1 + Basic 头 + 正则解析 multistatus（容忍任意 ns / XML 数字实体）
- 配置持久化 webdav_configs_v1；源集合注入 activeSourcesProvider
- 3 单测：解析/认证异常/Base64 头

### 4.5 CUE 分轨（T12，已测）

- `mm:ss:ff`（75 帧/秒）→ Duration；INDEX 01 起、INDEX 00 前奏；withEnds 推轨尾
- Track 增 cueStartMs/cueEndMs，播放加载后自动 seek
- 5 单测全过

### 4.6 MusicBrainz 刮削（T12，已测）

- recording 查询 + coverart 缩略图；UA + 1.3s 节流，429 中文异常
- 3 单测全过（query 构造 / artist 为空 / 节流）
