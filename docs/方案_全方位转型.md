# 星璃音乐 · 全方位应用转型方案（博客 + 多功能服务聚合）

> 定位提案（用户 2026-08-31）：星璃从「音乐播放器」演进为「个人媒体中心 / 全方位应用」——既承载自有博客内容，又聚合既有功能与服务。
> 关联：`docs/白皮书自用精简总结_v3.md`（铁律）、`docs/文档体系总览.md`、`docs/方案_ClassIsland联动.md`。
> 状态：方案稿 v0.1，待用户拍板范围后启动。

---

## 1. 现状盘点：星璃已经是什么

「全方位」不是从零转型——星璃已具备 8 项可聚合能力：

| # | 能力 | 载体 | 状态 |
|---|---|---|---|
| 1 | 智能播放（本地策展 + 意境场景 + 刮削） | 播放核心 | ✅ 生产 |
| 2 | 网络电台（公开电台目录/直播流） | radio_source | ✅ 生产 |
| 3 | 电台房（校园广播 / 一起听 / 点歌，relay 中转） | 社交模块 | ✅ 生产 |
| 4 | 投屏（局域网 HTML 播放页 + Range 流） | cast_stream_server | ✅ 生产 |
| 5 | 自建 Subsonic 服务器接入 | music_source | ✅ 生产 |
| 6 | 自研 OTA（GitHub Release + Pages 双源） | ota_service | ✅ 生产（clOTA） |
| 7 | 本地状态服务（NowPlaying HTTP API） | now_playing_server | 🆕 本轮（ClassIsland 联动） |
| 8 | 体素世界 / 开放世界玩法 | world 模块 | ✅ 生产 |

「全方位」= 把 2~8 与**自有博客**统合成一个入口分明、能力自洽的应用，而不是堆功能。

## 2. 转型定位与边界（铁律兼容性分析）

白皮书 v3 三条铁律（对照）：

| 铁律 | 内容 | 转型兼容性分析 | 结论 |
|---|---|---|---|
| 铁律 1 | 不做社交评论 | 博客是**自有内容输出**（单向发布），不是 UGC 评论区；电台房是**同频共听**（私密房间），非公开广场。均不引入公开评论/关注/私信。 | ✅ 兼容 |
| 铁律 2 | 不做云端推荐 | 博客与聚合服务全部**本机/自建**；不接任何推荐 API、不上传播放行为做推荐。探索页的「推荐」是本地曲库规则引擎（已有）。 | ✅ 兼容 |
| 铁律 3 | 不搞第三方代理源 + 不玩 Hi-Fi 玄学 | 聚合的是**自有服务**（投屏/电台/网盘/OTA），不代理第三方音源；Hi-Fi 相关只做工程向（EQ/均衡器是工具，不贩卖玄学）。 | ✅ 兼容 |

**定位一句话**：**「星璃音乐」是用户自己的媒体中枢——内容（本地/自建）+ 同频（电台/投屏）+ 表达（博客）+ 服务（OTA/状态 API），全部自有、可控、可离线。**

明确不做（红线，写进 README 与设置页「关于」）：公开注册、评论/弹幕、云端曲库、付费订阅、第三方代理音源。

## 3. 形态设计：三入口收敛

保持现有「5 Tab」骨架，转型体现在**第一个 Tab（主页）**与**「星璃世界」入口**的重构：

```
主页（Today）
  ├─ 博客头条（新增：最近 3 篇自有文章标题，点击进博客）
  ├─ 场景音乐（现有）
  └─ 热门歌单 / 最近播放（现有）
功能页（现有 5 Tab：主页/探索/曲库/星璃世界/我的）
  └─ 星璃世界（扩展为「服务中心」聚合页）
       ├─ 电台房 · 点歌（现有）
       ├─ 投屏（现有）
       ├─ 博客（新增：博文列表 + 阅读页）
       ├─ 自建服务器 / 公开电台（现有）
       ├─ ClassIsland 联动（现有方案，设置里显示服务地址）
       └─ 软件更新（OTA，现有）
```

> 对外仍是一个「音乐 App」，博客与服务是**后台能力**——避免变成四不像。设置里统一入口叫「星璃中心」。

## 4. 博客子模块（M1）

### 4.1 范围与铁律校验
- **单作者自有博客**：Markdown 文章 + 本地渲染（自有内容输出，无评论）。
- 文章目录：`<应用文档目录>/blog/`（Windows 与 Android 同构），支持 md 首部元信息（标题/日期/标签）。
- 阅读页：内置 Markdown 渲染器（现有依赖中 flutter_markdown 若已引入则复用，否则不新增依赖，用最小渲染）。
- **不上传、不联网**：博客完全本地，符合离线/自建定位。

### 4.2 交付物
| 文件 | 内容 |
|---|---|
| `lib/pages/blog/blog_list_page.dart` | 文章列表（时间倒序，卡片 + 标签过滤） |
| `lib/pages/blog/blog_reader_page.dart` | 阅读页（标题 + 日期 + 正文渲染） |
| `lib/services/blog/blog_store.dart` | 目录扫描 + md 解析（首部元信息） |
| `test/services/blog_store_test.dart` | 解析单测 |
| 设置页入口 | 设置→星璃中心→博客（仅启用后显示） |
| `assets/example_blog/` | 2 篇示例文章（引导用户放入自己的博客） |

### 4.3 与「文档体系」互不干扰
博客是**用户运行时内容**；仓库 `docs/` 是**开发治理文档**。两者物理分离（运行时文档目录 vs 仓库 docs/），仅共享「星璃中心」入口文案。
