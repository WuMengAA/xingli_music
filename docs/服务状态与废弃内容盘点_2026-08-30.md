## 四、存档不显示 —— 根因已定位，修复中

### UI 主因
世界 Tab（`world_page.dart`）只显示 3 个静态入口按钮，**不渲染任何存档内容**。注释明确写"已移除存档网格/骨架屏/空态"——方向性错误，用户要的是"重点端上来"。完整存档管理页 `VoxelSaveManagerPage` 有 3 个入口（world_page / voxel_main_menu_page / settings_item_registry），但藏在二级页。

### 数据回归 bug
commit `d315414`（0.26.8.29）把 `_migrateFromDocuments`（voxel_save.dart:116）迁移源误从 `getApplicationDocumentsDirectory()` 改成 `appDataDir()`，**老用户 Documents 里的旧档不再迁移** → 升级用户列表显示"暂无存档"。

### 修复方案（实施中）
1. 世界 Tab 内嵌渲染存档列表（复用卡片/进入逻辑），空态友好引导。
2. 迁移源改回 Documents，恢复老档迁移。
