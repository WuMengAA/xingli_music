# 星璃音乐 · 界面文案规范（极光玻璃 · 细化版）

> 实现唯一来源：`lib/core/terms/naming_dict.dart`（`Terms` 类）。
> 所有 UI 文案一律引用 `Terms.*`，**禁止硬编码**。新增文案先补词典，再引用。

## 1. 整体调性

- **语气**：温润、通透、带一点未来感，但不说教。
- **人称**：统一「你」，如「你的歌单」「为你推荐」。
- **断句**：短句为主，4~6 字；按钮 ≤ 4 字。
- **标点**：标题 / 按钮 / 标签**不加句号**；简短提示可加，尽量不用感叹号（紧急错误除外）。
- **翻译感**：避免直译，如「个人中心」不写「我的资料」、「歌单内页」不写「歌单详情」。

## 3. 各模块要点

- **底部导航**：主页 / 曲库 / 世界 / 探索 / 设置（「世界」图标旁可加小字「星璃」）。
- **音乐卡**：展开按钮「展开」；收起状态「正在播放 · 曲名」。
- **整页播放器**：进度 `3:42 / 5:10`；播放/暂停/上下首仅图标；循环三种态（单曲循环/列表循环/随机）；音效（原均衡器，预设：清澈/人声/重低音/古典/摇滚/自定义）；安睡（15/30/60 分钟、结束时停止）；音景（雨声/海浪/篝火/森林/风）；无歌词「纯音乐 · 无声词」；画面（B 站视频背景）；倍速 `1.0x` 等。
- **主页**：问候语 早上好/下午好/晚上好；标语「音乐是流动的极光」；场景卡英文小标签 `SCENE`；场景标题如「雨夜书房」「篝火露营」「深海冥想」。
- **曲库**：搜索「搜索歌曲、歌手或专辑…」；筛选 歌曲/专辑/在线/音景；最近在听；你的排行（周榜/月榜/总榜）；音乐时光机。
- **世界（星璃）**：页标题「星璃」；入口 荒野/雨林/雪原/极光；自由探索；世界规则；一起听；存档 / 读取。
- **探索**：搜索「搜索歌曲或场景…」；场景歌单；热门推荐；功能入口 聚合搜索/智能推荐/小璃/星璃世界；实验室。
- **设置**：分组 音频/画面/通知/实验/关于。
- **声景工坊**：拖拽方块到画布；奏响；分享你的音景。
- **小璃（AI 陪伴）**：输入框「跟小璃说点什么…」；代操作「小璃已帮你调整音量」。

## 4. 反馈与提示

- 成功：已收藏 / 已移除 / 已添加到歌单 / 歌单已保存。
- 错误（具体不恐慌）：网络未连接，请检查后重试 / 此歌曲无法播放 / 请授权存储访问 / 未找到相关内容，换个关键词试试。
- 空状态：这里还没有歌曲，去添加一些吧 / 创建你的第一个歌单 / 还没有存档，开始一场冒险吧。
- 加载：加载中… / 加载超时，点击重试。
- 安睡：将在 XX 分钟后停止。
