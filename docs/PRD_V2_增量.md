## 2. 用户故事

### M1 UI 统一与横屏适配
- **US-01** 作为用户，我希望所有页面采用统一的页面格式与组件，这样不同页面不会像来自不同 App。
- **US-02** 作为用户，我希望同类信息（歌名 / 歌手 / 时长 / 场景）在任何页面展示方式一致，这样我不用反复重新学习。
- **US-03** 作为用户，我横屏使用 App 时，希望布局自动重排（如曲库变多列、文件夹变左右双栏），这样不用歪着头看被拉伸的界面。

### M2 探索页 = 实验场所
- **US-10** 作为用户，我第一次进入探索页时，希望明确被告知「这里是实验场所」并征得同意，这样我能自主决定是否参与。
- **US-11** 作为探索者，我希望在探索页集中找到 AI 推荐 / 搜索 / 音效均衡器 / 2.5D 小游戏 / 心情分析 / 传感器等实验，这样我能一站式体验前沿能力。
- **US-12** 作为用户，我希望每个实验项都标明状态（实验中 / 稳定 / 已下线），这样我知道它的成熟度与风险。

### M3 曲库三种浏览样式
- **US-20** 作为用户，我希望用卡片样式快速浏览单曲，这样翻找快。
- **US-21** 作为用户，我希望用文件夹样式按本地目录层级浏览，这样我能按自己的文件组织找歌。
- **US-22** 作为用户，我希望用专辑样式按专辑聚合浏览，这样我能靠封面认专辑。

### M4 设置·音源
- **US-30** 作为用户，我希望「服务器」和「音源」合并在一处管理，这样我不会在两个入口之间来回找。
- **US-31** 作为用户，我希望音源按「本地目录 / 自建服务器 / 公开电台」清晰分组，这样我能快速配置并测试连接。

### M5 场景扩展
- **US-40** 作为用户，我希望在场景里用 2.5D 方块方式摆放音效（类我的世界），这样我能亲手搭建专属音景。
- **US-41** 作为用户，我希望自定义场景能列出、新增并编辑名称 / 显示 / 图标 / 默认背景音乐，这样我的场景更个人化。
- **US-42** 作为用户，我希望为场景自定义配色（主色 / 强调色 / 背景渐变），这样场景氛围由我决定。

### M6 通知（多合一）
- **US-50** 作为用户，我希望通知中心同时看到通知运行状态、播放媒体信息与控制、场景状态，这样我不用在多个页面之间切换。
- **US-51** 作为用户，我希望在通知中心能直接暂停 / 切歌、看到当前场景并快捷切换，这样操作更顺手。

## 4. UI 设计稿要点（组件 / 交互级，含横屏）

> 全部尺寸沿用 v1 Token（dp）；本节只描述**新增 / 变更**界面。

### 4.1 M1 全局统一 + 横屏

| 项 | 竖屏（默认，沿用 v1） | 横屏（宽 ≥ 600dp） |
|---|---|---|
| 页面模板 | `PageScaffold`：搜索栏(40) + 内容区(弹性) | 左侧固定导航 / 信息区（≤ 360dp）+ 右侧内容区（弹性）；搜索栏位于右内容区顶部 |
| 通用信息组件 | `InfoRow`：封面 48 / 歌名 / 歌手 / 时长，右对齐时长 | 同左；列表行高不变 |
| 命名词典 | 场景、曲库、歌曲、专辑、目录、音源、服务器、通知中心 —— 单一出处 | 同左 |
| Dock / 迷你播放器 | v1 底部药丸 + 双胶囊（不动） | 候选：A 左侧竖 Dock；B 底部收窄 Dock + 播放器扩展；C 仅内容重排（Q1 裁决） |
| 状态徽标 | `StateChip`：实验中 / 稳定 / 已下线 / 连接正常 / 失败 | 同左 |

### 4.2 M2 探索页 = 实验场所

- **默认态（未同意）**：全屏 Gate 卡片 —— 标题「探索实验室」、说明（实验性 / 可能不稳定 / 数据用途 / 可随时退出）、主按钮「同意并进入」、次按钮「暂不参与」；暂不参与时页面仅显示只读条款与再次进入按钮。
- **同意后**：顶部说明条（「这里是实验场所」+ 查看条款入口）+ 实验列表（网格 / 列表，横屏 ≥ 2 列）：每项 = 图标 + 名称 + 简介 + 状态徽标 + 进入按钮；「已下线」置灰不可点。
- **实验项页**：全屏路由进入，页内顶部常驻「实验」标识与「退出实验」说明。

### 4.3 M3 曲库三种浏览样式

- 搜索栏下方新增 `SegmentedButton` 样式切换器（卡片 / 文件夹 / 专辑三态）。
- **卡片样式**：2 列网格（横屏 4 列），卡片 = 封面 72 + 歌名 + 歌手 + 时长（沿用 v1 卡片几何）。
- **文件夹样式**：竖屏 = 可展开目录树（文件夹图标 + 名称 + 曲目数）；横屏 = 左目录树（master）+ 右歌曲列表（detail）。
- **专辑样式**：2 列网格（横屏 4 列）专辑卡 = 封面 + 专辑名 + 歌手；点开专辑 → 专辑曲目列表页（复用 `InfoRow`），点击即播。

### 4.4 M4 设置·音源

- 音源分类详情区重组为 3 个分组卡片：**本地目录 / 自建服务器 / 公开电台**；每组 = 组标题 + 「添加」按钮 + 条目列表（开关 / 编辑 / 删除 / 测试连接）。
- `server_settings_page` 瘦身：移除全局播放、粒子、关于等区块；仅保留音源相关逻辑（可内联到音源详情或作为纯音源管理子页）。
- 条目健康状态以 `StateChip` 展示（连接中 / 正常 / 失败 / 上次测试时间）。

### 4.5 M5 场景扩展

- **2.5D 音效编辑器**：等距 / 俯视 2.5D 方块画布（主区）+ 音效方块面板（侧栏，可拖拽到画布）+ 底部工具栏（试听 / 播放 / 撤销 / 重做 / 保存 / 清空）。竖屏画布居中、面板在上；横屏画布居左、面板居右。
- **自定义场景管理**：场景列表（内置 / 自定义分组，图标 + 名称 + 显示开关 + 来源标记）+「+ 新建场景」；编辑表单 = 名称 / 描述 / 心情 / 图标选择器 / 默认 BGM 选择器（从曲库选曲）/ 显示开关。
- **配色个性自定义**：场景页右上角**微光圆点**（沿用已裁决入口）→ 配色面板：主色 / 强调色 / 背景渐变（预设色板 + 自定义取色），应用到当前场景并持久化（写入 `Scene.visual` 等字段）。

### 4.6 M6 通知中心

- 设置页「通知」分类 = 三区块卡片（竖屏单列 / 横屏双列：媒体控制 + 场景状态并排）：
  ① 运行状态：后台播放 / 锁屏控件 / 通知栏 3 个开关；
  ② 播放媒体与控制：封面 + 歌名 / 歌手 + 播放暂停 / 上一首 / 下一首 + 进度条；
  ③ 场景状态：当前场景图标 / 名称 + 音景开关 + 场景快捷切换（下拉或横向 chips）。
